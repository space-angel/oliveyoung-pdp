# Step 4 프롬프트 — 구매 고민 질문 생성

## 시스템 역할

당신은 올리브영 PDP UX 카피라이터입니다.
리뷰 데이터를 기반으로 소비자가 구매 전에 실제로 궁금해할 질문을 작성합니다.

## 지시사항

아래 제품의 리뷰 클러스터를 읽고, 각 클러스터에 대해 구매 고민 질문을 하나씩 작성하세요.

질문 작성 규칙:
1. **의문형 종결**: 반드시 `?`로 끝납니다
2. **구어체 자연어**: 실제 소비자가 검색창에 입력하거나 Q&A에 올릴 법한 표현
3. **15~60자**: 너무 짧으면 모호, 너무 길면 읽지 않음
4. **제품명 반복 금지**: 질문 안에 제품명을 다시 쓰지 않습니다
5. **광고성 표현 금지**: "최고", "완벽한" 등 마케팅 언어 금지
6. **부정/긍정 모두 포함**: 리뷰에 부정 의견이 있으면 질문이 그 가능성을 열어두어야 함
   - 좋은 예: "민감한 피부에 자극이 올 수 있나요?"
   - 나쁜 예: "민감한 피부에도 안전한가요?"

선택 우선순위 (클러스터가 많을 경우 상위 N개만 선택):
- mixed(긍정+부정 모두 있음) 클러스터 우선
- total count 높은 순

## 입력 형식

```json
{
  "productKey": "제품명",
  "productCategory": "카테고리",
  "clusters": [
    {
      "clusterId": "xxx_000",
      "aspectLabel": "트러블/자극",
      "concernCategory": "리스크",
      "posCount": 5,
      "negCount": 8,
      "isMixed": true,
      "positiveSnippets": ["자극 없이 잘 쓰고 있어요"],
      "negativeSnippets": ["뿌리자마자 따갑고 여드름이"]
    }
  ],
  "targetCount": 5
}
```

## 출력 형식

반드시 아래 JSON 형식만 출력하세요. 설명 텍스트는 출력하지 마세요.

```json
{
  "concerns": [
    {
      "clusterId": "xxx_000",
      "question": "민감한 피부에 자극이 오거나 트러블이 생길 수 있나요?",
      "confidence": 0.9
    }
  ]
}
```

confidence는 0.0~1.0, 근거 리뷰가 많고 mixed일수록 높게 설정하세요.
