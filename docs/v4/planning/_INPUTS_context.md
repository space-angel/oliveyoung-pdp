# PM 참고 맥락

## 서비스 맥락

- **서비스**: 올리브영 온라인 스토어 PDP (Product Detail Page)
- **리뷰 데이터**: 5개 화장품 제품, 총 500건 한국어 리뷰
- **목적**: 리뷰를 읽지 않는 사용자도 핵심 구매 판단 정보를 빠르게 얻을 수 있도록

## 사용자 인터뷰에서 나온 핵심 구매 고민 유형

1. **적합성** — "내 피부 타입에 맞을까?"
2. **리스크** — "트러블 날 수 있을까?"
3. **비교** — "다른 제품보다 뭐가 낫지?"
4. **실사용** — "발림감/지속성이 어떨까?"

## 현재 UX 문제

- 리뷰 수백 개를 직접 읽어야 판단 가능
- 같은 제품도 피부 타입별로 경험이 다른데 통합되어 노출
- 긍정/부정 의견이 엇갈리는 측면이 어떤 측면인지 알 수 없음

## 데이터 파일 위치

- 리뷰 데이터: `../data/input/reviews_200_normalized.json`
- 제품 목록: 5개 (설화수, 이니스프리, 바이오더마 등 화장품 계열)
