## 모델과 실행 방식

실행 주체는 현재 Codex 세션의 GPT-6 계열 모델이다. 정확한 배포/API 모델 ID, effort/thinking 설정값, temperature는 세션에서 확인할 수 없어 **미노출**로 기록한다. 특정 모델 ID나 high effort·온도 0 실행을 주장하지 않는다. 별도 유료 API 호출이나 다른 에이전트 실행은 하지 않았다.

`eval/gold/regold_prompt_v1.md` 전체를 읽어 태깅 지침으로 적용했다. 각 패스는 5건씩 40청크이며, 2패스에서는 원문과 해당 1패스 결과를 다시 읽고 14축 누락 여부를 검토했다. **같은 대화 세션에서 직접 수행했으며 청크마다 독립된 모델 요청/문맥은 아니다.** 프롬프트를 별도 API의 단독 system 역할에 주입한 실행도 아니다. 따라서 별도 API로 프롬프트·모델 설정을 고정한 실험과 동일하게 취급해서는 안 된다.

v1 태그 본문은 두 패스를 작성하는 동안 읽지 않았다. 2패스 후보를 저장·검증한 뒤 `diff_tags.py`가 v1을 읽어 사람 판정용 리포트를 생성했다. 대조 결과에 맞춰 v2를 재수정하지 않았다. 입력 표본과 v1 파일은 변경하지 않았다.

## 반드시 유지할 해석상의 한계

`가성비` 정의는 **v1에서 이 축이 많이 누락됐다는 관찰 뒤에 의도적으로 강화한 프롬프트**다. 특정 v1 인용을 보고 태깅하지 않았어도 완전히 독립적인 재작성은 아니다. 재구매 의사·구매 만족·구성·소모량을 가성비로 포함했고, 이는 단순히 가격이 싸다는 주장과 다르다. 예를 들어 `64005851`의 구매 만족도 이 확장 정의에 따른 태그다.

v2를 채점 기준으로 사용하면 재현율의 분모와 평가 대상이 바뀐다. **v1 기준 과거 채점 수치와 v2 기준 새 수치를 나란히 놓고 개선/악화를 주장하면 안 된다.** 여기서는 태그 차이만 제출하며 기존 태거를 v2 기준으로 재채점하거나 v2를 자동 채택하지 않았다.

14축을 전부 훑더라도 리뷰당 최대 5개 계약 때문에 모든 언급을 산출할 수는 없다. `8653077`, `10151614`, `38248029`, `61892256`, `63456706` 등은 추가 축을 확인했지만 상한 때문에 일부를 담지 못했다. 각 청크의 검토 메모에 남겼다. 이 상한도 재현율 기준의 한계다.
